# 1arutyun — Personal Musician Website & Site Builder (`/admin`)

Минималистичный авторский сайт музыканта **1arutyun** с собственным визуальным конструктором `/admin`.

---

## ✨ Что реализовано

1. **Без громоздких прямоугольников и карточек + 3D-анимация обложек:**
   - Свободная журнальная (editorial) верстка: чистая типографика, воздух, тонкие разделительные линии (`1px`) и асимметричная сетка без банальных «рамок/прямоугольников» вокруг каждого блока.
   - Сохранена **интерактивная 3D-анимация обложек песен** с мягким световым бликом при наведении курсора (без выезжающей виниловой пластинки).

2. **Светлая тема по умолчанию + Темная тема:**
   - По умолчанию включена теплая светлая тема (`#faf8f5`), переключатель `☀ / ☾` в шапке мгновенно включает темную тему (`#0c0c0e`).

3. **Английский язык по умолчанию (`EN`) + Русская версия (`RU`):**
   - По умолчанию сайт открывается на английском языке (`EN`), переключение `EN / RU` доступно в шапке.

4. **Структура страниц (без нагромождения главной):**
   - **Главная страница (`/`)** — краткий манифест автора, портрет и список вышедших релизов с описанием и 3D-обложками.
   - **Отдельная страница каждого релиза (`/release/undefined` и др.)** — полная информация о релизе, список треков, **ссылки на все стриминговые площадки** (*Spotify, Apple Music, YouTube Music, Deezer, Tidal, SoundCloud* и любые другие) и видеоклипы, относящиеся к релизу.
   - **Страница видео (`/videos`)** — кинозал для просмотра видеороликов прямо на сайте. Поддерживает как **прямую загрузку видеофайлов (`.mp4`, `.webm`, `.mov`)** с компьютера, так и **YouTube-видео** (исправлена ошибка `Video configuration error` за счет корректного HTTP-сервера, `origin` и `Referrer-Policy: strict-origin-when-cross-origin`).
   - **Страница «Thoughts / Мысли» (`/thoughts`)** — авторская лента по типу Telegram-канала с поддержкой закрепленных постов, текста, фотографий, встроенных видео и реакций `🤍`.

5. **Полноценная админ-панель / конструктор сайта (`/admin`):**
   - Доступна по адресу [http://localhost:3000/admin](http://localhost:3000/admin).
   - **Вкладка 1 (Главная и О себе):** изменение имени, загрузка аватара и портрета, редактирование текстов манифеста (EN/RU), даты следующего релиза и ссылок на соцсети.
   - **Вкладка 2 (Релизы и Площадки):** добавление и редактирование релизов, загрузка обложек, управление списком стриминговых площадок и ссылок для каждого релиза отдельно.
   - **Вкладка 3 (Видеозаписи):** загрузка собственных видеофайлов (`.mp4`, `.mov`, `.webm`) с компьютера или добавление ссылок на YouTube, загрузка обложек-превью.
   - **Вкладка 4 (Канал «Мысли»):** публикация и редактирование постов, закрепление записей, прикрепление фото и видео.
   - **Вкладка 5 (Медиатека):** управление всеми загруженными фото и видеофайлами.

---

## 🚀 Как запустить

Сервер уже запущен! Вы можете сразу открыть:
- **Сайт:** [http://localhost:3000](http://localhost:3000)
- **Админ-панель:** [http://localhost:3000/admin](http://localhost:3000/admin)

Для повторного запуска в будущем просто дважды кликните по файлу **`start.bat`** или выполните в терминале:
```bash
node server.js
```
